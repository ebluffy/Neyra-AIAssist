# Neyra desktop

Самостоятельный UI для ежедневного чата и управления своим ПК. За основу визуального языка взяты роли цветов существующей Neyra: спокойная тёмная/светлая поверхность, cyan для выбранного действия, ясный текстовый статус. Исходники dashboard не используются; общая только иконка продукта.

Чат — основной экран. Настройки сервера и доступ к ПК разделены. Stop всегда виден; подтверждение требует конкретного действия и по умолчанию фокусирует отказ. Короткие русские подписи, системный шрифт, контрастные границы, минимальная ширина 620 px, без декоративной анимации. Токены не появляются в статусах и диагностике. Loading, offline, пустой список и ошибка дают понятный следующий шаг.

Экран «Быстрые команды»: список карточек (название, триггеры, шаги, включена), запуск, проверка политики без выполнения, форма и YAML-редактор, поле «выполнить фразу» без сервера, отдельный блок ошибок файлов (файл, строка, причина, работает ли последняя версия). Пустое состояние объясняет три способа создания. Статус запуска — в одной живой области, Stop остаётся в шапке. «Настройки» — имя ПК, тема, графика, срок журнала, папка данных, перенос конфигурации с предпросмотром; сообщение о восстановленных файлах стоит первым и не скрывается. «Доступ к ПК» — разрешения и журнал. Все диалоги — нативный `<dialog>` с возвратом фокуса, Escape закрывает, опасное действие по умолчанию отклонено.
