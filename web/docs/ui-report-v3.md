## 2. Архитектурные решения и реализация идентичности

### 2.1 Контракт идентичности `person_id` ([`web/docs/identity.md`](file:///run/media/ebluffy/Games/!Other/!Dev/AIAssist/web/docs/identity.md))
- В соответствии с заданием, бэкенд-ядро не модифицировалось напрямую. Сформирован исчерпывающий архитектурный контракт для бэкенд-команды.
- **Единый субъект**: Введён единственный идентификатор человека — `person_id` (формат `u_` + 26 символов ULID).
- **Привязка площадок**: Таблица `account` связывает `person_id` с площадками (`discord`, `web`, `telegram`). `discord_id` (Snowflake) является исключительно атрибутом привязки и никогда не используется как внешний ключ в памяти, тредах диалогов, правах или заметках.
- **Правила объединения (Merge Rules)**:
  - Автоматическое объединение по совпадению почты или ника **запрещено** (во избежание захвата аккаунтов).
  - Слияние выполняется строго вручную пользователем или администратором.
  - Сохраняется более старый `person_id` как старший. Младший помечается как `merged_into` с сохранением полной истории в таблице `person_merge_audit` и гарантией отката (undo) в течение 30 дней.

   - Вторичный вход: Email + Пароль оформлен в виде аккуратного раскрывающегося блока (*«Войти по email»*), сохраняя полную функциональность для локальных/тестовых администраторов.

## 4. Универсальное контекстное меню продукта

Реализовано в [`web/src/components/ui/ContextMenu.tsx`](file:///run/media/ebluffy/Games/!Other/!Dev/AIAssist/web/src/components/ui/ContextMenu.tsx) и [`web/src/lib/context-menu/registry.ts`](file:///run/media/ebluffy/Games/!Other/!Dev/AIAssist/web/src/lib/context-menu/registry.ts).

1. **Покрытие поверхностей**:
   - `chat-message`: Копировать текст, цитировать, повторить запрос, озвучить (заглушка «Скоро»), удалить.
   - `chat-item` (сайдбар): Переименовать, закрепить, экспорт (заглушка «Скоро»), копировать ID диалога, удалить.
   - `note-item`: Редактировать, копировать заметку, удалить.
   - `composer`: Очистить поле ввода, прикрепить файл (заглушка «Скоро»).
   - `thread-header`: Очистить контекст, копировать ID треда.
   - `admin-row`: Объединить профиль, копировать `person_id`, сменить роль, бан, войти как пользователь (заглушка).
   - `invite-row`: Копировать код, копировать ссылку, отозвать инвайт, удалить.
   - `link`: Копировать адрес ссылки, открыть в новой вкладке.
   - `selection`: Копировать выделенный фрагмент, цитировать в поле чата.
2. **Соблюдение правил доступности и нативности**:
   - **Не перехватывает** нативное контекстное меню внутри полей ввода (`input`, `textarea`, `[contenteditable]`) и при выделении кода внутри блоков `<pre>`.
   - Комбинация **`Shift + ПКМ`** всегда открывает стандартное браузерное контекстное меню.
   - Опция в настройках *«Контекстное меню Neyra»* позволяет полностью отключить кастомное меню в пользу нативного.
   - Клавиатурная навигация: стрелки Вверх/Вниз, `Enter`, `Escape`, автоматический возврат фокуса на вызвавший элемент.
   - Удержание касания (Long-press): 500 мс на тач-устройствах с отменой при сдвиге пальца более 10px.
   - Edge Clamping: автоматический отступ от краёв экрана минимум 8px, чтобы меню никогда не выпадало за границы вьюпорта.

## 5. Аудиосинтез интерфейса (WebAudio)

Реализован в [`web/src/lib/ui-sounds.ts`](file:///run/media/ebluffy/Games/!Other/!Dev/AIAssist/web/src/lib/ui-sounds.ts).
- **Константа ослабления**: `export const UI_SOUND_GAIN = 0.25` жестко внедрена во все узлы GainNode синтезатора без возможности обхода.
- **Чистый WebAudio API**: Ноль внешних аудиофайлов, ноль сетевых запросов.
- **Звуковая карта**:
  - Клик по кнопке: мягкий щелчок (950 Гц $\to$ 400 Гц, 20 мс).
  - Открытие модального окна: деликатный восходящий перезвон (450 Гц $\to$ 850 Гц, 35 мс).
  - Закрытие модального окна: нисходящий тон (750 Гц $\to$ 380 Гц, 30 мс).
  - Отправка сообщения: восходящий свист-тон (320 Гц $\to$ 880 Гц, 45 мс).
  - Оповещение/ответ: двухтональный колокольчик D5/A5 $\to$ D6 (140 мс).
  - Ошибка/предупреждение: глухой низкий тон (220 Гц $\to$ 110 Гц, 60 мс).
- **Управление**: Включение/выключение в «Настройки $\to$ Внешний вид», соблюдение флага `prefers-reduced-motion`.
