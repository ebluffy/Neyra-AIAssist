# Neyra Web — Дизайн-система (Монохромная среда)

Обязательный нормативный документ для всех поверхностей веб-клиента (`/login`, `/signup`, `/reset-password`, `/chat`, модальное окно настроек, модальное окно администрирования).
Любое отклонение от зафиксированных ниже значений считается регрессией и дефектом сборки.

Направление: **строгий инструментальный монохром** (pure monochrome instrument).
База: глубокий чёрный `#000000`, иерархия поверхностей `#0a0a0a → #121212 → #1a1a1a`, чистый белый `#ffffff` как единственный функциональный акцент.
Красный сигнал `--danger` (`#ef4444`) разрешён исключительно для критических сбоев, валидации форм и деструктивных операций подтверждения удаления.

---

## 1. Анти-слоп кодекс (жесткие запреты)

1. **Никаких дефолтных рамок**: кнопки, ссылки и поля ввода обязаны использовать нормализованный CSS-ресет (`tokens.css`). Рамки задаются исключительно семантическими утилитами компонентов.
2. **Никаких цветных градиентов**: запрещены фиолетовые, неоновые, янтарные и радужные пятна, цветные блюры и свечения.
3. **Единая библиотека иконок**: только `lucide-react`, размер 14–16px (20px для кнопки отправки сообщения), толщина штриха `strokeWidth={1.5}`. Запрещены эмодзи в интерфейсе.
4. **Честность данных**: запрещены выдуманные цифры, ложные счетчики и фейковый uptime. В пустых состояниях явно указывается фактический статус.
5. **Никаких кричащих плашек**: запрещены яркие uppercase бейджи («SOON», «ДИАЛОГ») на каждой строке меню. Статусы готовности обозначаются аккуратным приглушенным текстом `--text-subtle`.
6. **Никаких `transition: all`**: переходы анимируются строго по свойствам `transform`, `opacity`, `background-color`, `border-color` (длительность 120–160ms, кривая `cubic-bezier(0.22, 1, 0.36, 1)`).
7. **Семантические токены**: в JSX запрещены сырые hex/rgb цвета. Все стили ссылаются на `var(--...)` токены дизайн-системы.
8. **Доступность кликов и фокуса**: все интерактивные контролы имеют минимальную площадь попадания 40×40px (на мобильных устройствах — 44×44px). Кольцо клавиатурного фокуса `:focus-visible` — 2px `--accent` с отступом 2px.

## 2. Трёхуровневая архитектура токенов

### Уровень 1: Примитивы (Primitives)
Базовые палитры серого, шкала радиусов, типографическая сетка и временные функции:
- Нейтрали: `zinc-950` (`#0a0a0a`), `zinc-900` (`#121212`), `zinc-850` (`#1a1a1a`), `zinc-500` (`#71717a`), `zinc-400` (`#a1a1aa`), `zinc-100` (`#f4f4f5`), белый (`#ffffff`), черный (`#000000`).
- Ошибки: `red-500` (`#ef4444`), `red-950/20` (`rgba(239, 68, 68, 0.12)`).
- Пространство (Space): 4px (`0.25rem`), 8px (`0.5rem`), 12px (`0.75rem`), 16px (`1rem`), 20px (`1.25rem`), 24px (`1.5rem`), 32px (`2rem`), 40px (`2.5rem`).
- Радиусы: `sm` (6px), `md` (10px), `lg` (14px), `full` (9999px).

### Уровень 2: Семантические токены (Semantic Tokens)
Назначают роли интерфейса в `web/src/app/globals.css`:

```css
:root {
  color-scheme: dark;

  /* Поверхности */
  --bg:             #000000;   /* Базовый холст приложения */
  --surface:        #0a0a0a;   /* Сайдбар, модальные карточки */
  --surface-2:      #121212;   /* Поля ввода, панели, пузыри сообщений */
  --surface-3:      #1a1a1a;   /* Hover, активные элементы списка */
  --border:         rgba(255, 255, 255, 0.08);  /* Декоративные разделители */
  --border-strong:  rgba(255, 255, 255, 0.16);
  --border-control: rgba(255, 255, 255, 0.36);  /* Границы контролов (>= 3:1 WCAG SC 1.4.11) */

  /* Типографика */
  --text:           #f4f4f5;   /* Основной высококонтрастный текст (19.11:1) */
  --text-muted:     #a1a1aa;   /* Вторичные подписи, подсказки (8.19:1) */
  --text-subtle:    #8e8e99;   /* Плейсхолдеры, третичные пояснения (6.48:1) */

  /* Функциональный акцент */
  --accent:         #ffffff;   /* Белый акцент */
  --accent-hover:   #e4e4e7;
  --accent-ink:     #000000;   /* Контрастный текст на акцентной кнопке (21.0:1) */
  --accent-quiet:   rgba(255, 255, 255, 0.08);

  /* Системные статусы */
  --danger:         #f87171;   /* Ошибка с повышенной яркостью (5.91:1) */
  --danger-quiet:   rgba(239, 68, 68, 0.14);
  --success:        #e4e4e7;   /* Нейтральный успех */

  /* Скругления и тени */
  --radius-sm:      6px;
  --radius:         10px;
  --radius-lg:      14px;
  --radius-full:    999px;
  --shadow-panel:   0 1px 0 rgba(255, 255, 255, 0.05) inset, 0 8px 24px rgba(0, 0, 0, 0.6);
}
```

### Уровень 3: Компонентные правила (Component Contracts)
1. **Button**:
   - `primary`: фон `--accent`, текст `--accent-ink`, без рамки (21.0:1).
   - `secondary`: фон `--surface-2`, рамка `--border-control` (3.31:1), текст `--text`, при наведении `--surface-3`.
   - `ghost`: фон прозрачный, без рамки, текст `--text-muted`, при наведении `--surface-3`.
   - `danger`: текст `--danger`, при наведении фон `--danger-quiet`.
2. **TextField / PasswordField / Select**:
   - Высота 44px (`h-11`), скругление 10px (`rounded-[var(--radius)]`), фон `--surface-2`.
   - Рамка `--border-control` (3.31:1), при фокусе `--accent` с фокусным кольцом 2px.
   - При ошибке: рамка `--danger`, кольцо `--danger`.
   - Глазок пароля: 40×40px хитбокс, прозрачный фон, без бордера, иконка 16px.
3. **Chip**:
   - Фон `--surface-2`, граница `--border-control` (3.14:1), текст `--text`.
   - Наведение: легкий подъем `-translate-y-px`, фон `--surface-3`, граница `--accent`.
4. **Switch / Radio / Checkbox**:
   - Границы неактивного состояния строго используют токен `--border-control` (3.31:1), активного — `--accent`.

## 3. Аудит контрастности (WCAG 2.2 AA)

Все пары цветов проверены программным скриптом `web/scripts/contrast-audit.mjs` по расчету W3C relative luminance на живом DOM (`web/docs/contrast.json`):

| **Основной текст** (`--text` `#f4f4f5`) | Черный холст (`--bg` `#000000`) | **19.11:1** | ≥ 4.5:1 (Normal Text) | **PASS (AAA)** |
| **Основной текст** (`--text` `#f4f4f5`) | Панель (`--surface-2` `#121212`) | **17.04:1** | ≥ 4.5:1 (Normal Text) | **PASS (AAA)** |
| **Вторичный текст** (`--text-muted` `#a1a1aa`) | Черный холст (`--bg` `#000000`) | **8.19:1** | ≥ 4.5:1 (Normal Text) | **PASS (AAA)** |
| **Вторичный текст** (`--text-muted` `#a1a1aa`) | Панель (`--surface-2` `#121212`) | **7.31:1** | ≥ 4.5:1 (Normal Text) | **PASS (AA)** |
| **Третичный текст** (`--text-subtle` `#8e8e99`) | Черный холст (`--bg` `#000000`) | **6.48:1** | ≥ 4.5:1 (Normal Text) | **PASS (AA)** |

## 4. Спецификации поверхностей и адаптивность

### 4.1. Авторизация (`/login`, `/signup`, `/reset-password`)
- Центрированная карточка 400px с монохромным логотипом Neyra.
- Поля ввода 44px с аккуратными подписями над полями.
- Кнопка Discord: нейтральная темная монохромная плашка без фирменных фиолетовых оттенков.
- Блок ошибки: `role="alert"`, плашка `--danger-quiet` с четким текстом проблемы.

### 4.2. Чат (`/chat`)
- Рабочая область: колонка сообщений шириной до 720px.
- Пустое состояние: логотип 40px, понятное пояснение, быстрые чипсы сценариев над полем ввода.
- Поле ввода (Composer): контейнер с внутренним паддингом 10px, автоувеличение высоты, кнопка отправки со стрелкой 20px, без посторонних внутренних рамок.
- Сообщения: пузырь пользователя справа (`--surface-2`), ответ ассистента слева без подложки с Markdown-форматированием и переносом длинных строк `[overflow-wrap:anywhere]`.

### 4.3. Панель треда (Thread Panel)
- Правая колонка 320px на десктопе, полноэкранная шторка с затемнением на мобильных устройствах.
- Вкладки («О диалоге», «Закреплённые», «Вложения», «Голос», «Настройки») выстроены в одну строку с плавным горизонтальным скроллом без неаккуратных переносов в две строки.
- Честные подписи: «История хранится на сервере и доступна на всех устройствах».

### 4.4. Боковая панель (Sidebar)
- 264px на десктопе, выдвижная шторка на мобильных экранах (`< 1024px`).
- Верх: логотип и кнопка `+ Новый чат`.
- Пустое состояние списка чатов: лаконичный текст без дублирующих кнопок создания.
- Активный чат: мягкая фоновая подсветка `--surface-3` без асимметричных левых полос.
- Подвал: аватар профиля, имя, статус прав и всплывающее меню перехода в настройки и админку.

### 4.5. Модальное окно настроек (Settings Dialog)
- Компактный размер: `max-w-[680px] h-[min(540px,88vh)]`.
- Левая навигация: колонка 210px с чистыми пунктами меню.
- Вкладка профиля: крупный аватар, имя, почта, роль в системе, честная плашка об управлении данными администратором.
- Переключатели (Switches): размер 44×24px с плавным ходом и состоянием фокуса.

### 4.6. Модальное окно администрирования (Admin Dialog)
- Единственная точка входа для управления системой (`admin-dialog.tsx`), легаси-страницы `/admin/*` изолированы.
- Навигация: аккуратные пилюли без рамок и без левых полос. Заголовки групп: 11px uppercase `--text-subtle`, отступ 16px.
- Вкладка «Обзор»: скелетон-карточки при первичной загрузке вместо блокирующего текста «Загрузка…», честный статус «служба neyra-core».
- Вкладка «Доступ»: счетчики скрыты до завершения загрузки; радио-переключатели режима регистрации расположены слева с акцентной обводкой активного варианта.

### 4.7. Мобильный вьюпорт 390×844px
- Все интерактивные элементы имеют высоту не менее 44px для комфортного тача.
- Отсутствие горизонтального вылета и скролла страницы (`overflow-x: hidden`).
- Горизонтальные вкладки снабжены плавным скроллом и скрытыми скроллбарами.

### 4.8. Доступность при масштабировании 200% (WCAG Zoom Reflow)
- При 200% зуме контент плавно перестраивается в одну колонку без потери текста и управляющих элементов.
