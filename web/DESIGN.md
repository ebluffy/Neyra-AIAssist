# Neyra Web — дизайн-система v2 (Монохром, Волна 3)

Обязательный документ для всех экранов сайта (`/login`, `/signup`, `/chat`, `/admin/*`, `/reset-password`, `/`).
Любое отклонение от значений ниже — только правкой этого файла в том же коммите.

Направление: **строгий монохромный инструмент** (pure monochrome instrument).
База: глубокий чёрный `#000000`, оттенки серого и белый `#ffffff` как единственный функциональный акцент.
Никаких цветных акцентов (янтарных, оранжевых, фиолетовых). Красный `--danger` допустим исключительно как сигнал ошибки валидации или системного сбоя.

## 1. Запрещено (анти-слоп гейты)

1. Никаких цветных градиентов (фиолетовых, синих, янтарных), размытого «стекла» на всём подряд, неоновых теней.
2. Никаких эмодзи вместо иконок. Все иконки — библиотека `lucide-react`, толщина `strokeWidth={1.5}`.
3. Никаких выдуманных цифр, отзывов, фейковых метрик.
4. Никаких надписей КАПСОМ с разрядкой (eyebrow вроде «ДИАЛОГ», «ФУНКЦИИ»), никаких декоративных цветных кружков.
5. Никаких `transition: all`. Анимации только для `transform` и `opacity` (120–160ms, кубическая безье `cubic-bezier(0.22, 1, 0.36, 1)`).
6. Никакого текста-заглушки вида «Lorem ipsum».
7. Ни одного литерального цвета hex или rgb в JSX/компонентах. Все значения только через CSS-переменные `var(--...)`.
8. Никаких неинформативных текстовых кнопок в утилитарных действиях: действия с понятной метафорой (отправить, стоп, новый чат, копировать, удалить, обновить, выход, назад, разблокировать) оформляются иконочной кнопкой с `aria-label` и тултипом при наведении. Текст остаётся только у первичных кнопок форм («Войти», «Зарегистрироваться») и подтверждений опасных действий в модальных окнах.
9. Центрировать разрешено только пустое состояние чата и карточки авторизации. Контент таблиц и админки — по левому краю.
10. Скругления и отступы строго из шкалы токенов.

## 3. Каркас и UX экранов

### Чат (`/chat`)
- Сайдбар: на десктопе 264px, на экранах `< 1024px` — шторка-drawer (`-translate-x-full`), которая стартует закрытой и открывается кнопкой в шапке.
- Сверху сайдбара: монохромный логотип `Neyra` + иконка нового чата `Plus` с тултипом «Новый чат».
- Список тредов: обычный регистр, активный пункт подсвечен `--surface-3` с белой полосой 2px слева.
- Профиль внизу сайдбара: одна строчка (имя/email + роль), без дублирования email.
- Шапка: название треда, индикатор контекста, кнопка меню треда с опциями: переименовать, копировать ссылку, удалить.
- Ошибка чата: понятная причина сбоя (при rate limit ядра — человеческое описание «Лимит запросов провайдера исчерпан» + подсказка времени сброса); кнопки «Повторить» и «Удалить» — аккуратные иконки с тултипами.

### Админка (`/admin/*`)
- Шапка админки: логотип, имя пользователя и роль в одну строку, кнопка перехода на сайт и кнопка выхода (иконка с тултипом).
- Навигация: на десктопе компактные пилюли, на мобильном (`< 1024px`) — выпадающее мобильное меню / шторка разделов.
- Статус системы: честные градации `ok`, `degraded` (при ограничении ядра), `down`, с указанием времени и причины.
- Таблицы: адаптивные карточки на мобильных устройствах, кнопки действий в строках (удаление, блокировка, сброс пароля, копирование) — иконки `lucide` с мгновенным тултипом.
- Без пустых плейсхолдеров сборки: честный статус «не задано в .env».

### Вход и регистрация (`/login`, `/signup`)
- Монохромный логотип Neyra.
- Плашка инвайта: строгая нейтральная подложка `--surface-2` с тонкой рамкой и иконкой.
- Никаких цветных кнопок.

## 4. Доступность
- `:focus-visible`: кольцо 1px белого цвета `--accent` с отступом 2px.
- Все иконочные кнопки обязательно снабжаются `aria-label` и стилизованным всплывающим тултипом.
- `prefers-reduced-motion` полностью отключает перемещения и переходы.
