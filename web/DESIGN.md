# Neyra Web — дизайн-система v1

Обязательный документ для всех экранов сайта (`/login`, `/signup`, `/chat`, `/`).
Любое отклонение от значений ниже — только правкой этого файла в том же коммите.

Направление: **спокойный инструмент** (quiet instrument). Тёмная нейтральная база,
одна тёплая сигнальная краска, тонкие волосяные границы, плотная типографика,
никакой декоративной мишуры. Референсы по духу: Claude, Linear, Vercel dashboard —
не копия, а уровень аккуратности.

## 1. Запрещено (анти-слоп)

1. Никаких фиолетово-синих градиентов, glassmorphism-блюра «на всём», неоновых свечений.
2. Никаких эмодзи вместо иконок. Иконки — `lucide-react`, толщина 1.5, размер 16/20.
3. Никаких придуманных цифр, отзывов, логотипов клиентов, «10 000 пользователей».
4. Никаких мелких надписей КАПСОМ с разрядкой над заголовками (eyebrow), никаких
   декоративных точек статуса и стрелок «→» внутри текста ссылки.
5. Никаких `transition: all`, анимаций `width/height/top/left`. Только `transform`/`opacity`.
6. Никакого текста-заглушки вида «Lorem» и «Ваш текст здесь».
7. Ни одного литерального цвета или `font-family` вне блока токенов.
8. Никаких двух одинаковых по весу акцентных кнопок на экране.
9. Центрировать разрешено только пустое состояние и карточку входа. Всё остальное — по левому краю.
10. Скругления только из шкалы токенов, не «на глаз».

## 2. Токены

Единственный источник — `src/app/tokens.css` (или `@neyra/ui` tokens), объявленный в `:root`.
Tailwind-классы используют `var(--…)`; произвольные hex в JSX запрещены.

```css
:root {
  color-scheme: dark;

  /* поверхность */
  --bg:            #08090a;   /* фон приложения */
  --surface:       #101113;   /* панели, сайдбар */
  --surface-2:     #16181b;   /* сообщение пользователя, поля ввода */
  --surface-3:     #1d2024;   /* hover, выделение */
  --border:        rgba(255,255,255,0.07);
  --border-strong: rgba(255,255,255,0.14);

  /* текст */
  --text:          #e9eaec;
  --text-muted:    #9a9fa6;
  --text-subtle:   #6b7178;

  /* сигнал */
  --accent:        #e4b15c;   /* тёплый янтарь: фокус, отправка, активный пункт */
  --accent-hover:  #eec27c;
  --accent-ink:    #1a1207;   /* текст на акценте */
  --accent-quiet:  rgba(228,177,92,0.12);

  /* статусы */
  --danger:        #e5686b;
  --danger-quiet:  rgba(229,104,107,0.12);
  --success:       #58b98a;

  /* типографика */
  --font-sans: var(--font-inter), system-ui, sans-serif;
  --font-mono: var(--font-mono-jetbrains), ui-monospace, monospace;
  --text-xs: 12px;  --leading-xs: 16px;
  --text-sm: 13px;  --leading-sm: 20px;
  --text-base: 15px; --leading-base: 24px;
  --text-lg: 18px;  --leading-lg: 26px;
  --text-xl: 22px;  --leading-xl: 30px;
  --text-2xl: 32px; --leading-2xl: 40px;
  --text-3xl: 44px; --leading-3xl: 52px;

  /* геометрия */
  --radius-sm: 6px;
  --radius: 10px;      /* контролы */
  --radius-lg: 14px;   /* панели, композер */
  --radius-full: 999px;
  --space-1: 4px;  --space-2: 8px;  --space-3: 12px; --space-4: 16px;
  --space-5: 20px; --space-6: 24px; --space-8: 32px; --space-10: 40px;

  /* движение */
  --ease-out: cubic-bezier(0.22, 1, 0.36, 1);
  --dur-fast: 120ms;
  --dur: 160ms;

  /* слой */
  --shadow-panel: 0 1px 0 rgba(255,255,255,0.04) inset, 0 8px 24px rgba(0,0,0,0.35);
}
```

Шрифты — `next/font/google`: `Inter` (переменная, латиница + кириллица) и `JetBrains Mono`
для кода. Заголовки — тот же Inter, `letter-spacing: -0.02em`, вес 600 (не 700-900).

## 3. Каркас приложения

```
┌─────────────┬──────────────────────────────────────────────┐
│ sidebar     │ header 56px: заголовок треда · действия       │
│ 264px       ├──────────────────────────────────────────────┤
│             │ лента сообщений, колонка max 720px, центр     │
│             │                                              │
│             ├──────────────────────────────────────────────┤
│ user menu   │ композер: sticky, max 720px                   │
└─────────────┴──────────────────────────────────────────────┘
```

- Сайдбар: `--surface`, справа волосяная граница. Сверху логотип-знак + «Neyra»
  (16px, 600). Ниже кнопка «Новый чат» (secondary, на всю ширину, иконка `Plus`).
  Список чатов — 13px, пункт 34px, hover `--surface-3`, активный — `--accent-quiet`
  плюс янтарная полоска 2px слева. Снизу — карточка пользователя: аватар-инициал
  24px, email 12px `--text-muted`, кнопка выхода (`LogOut`, ghost, 28px).
- При ширине < 900px сайдбар уезжает в drawer (`translateX`), открывается кнопкой
  `PanelLeft` в хедере, закрывается по Esc и по клику вне.
- Хедер: 56px, `--bg` с нижней границей; слева (на мобильном) кнопка меню, затем
  название треда (`--text-base`, 500, обрезка многоточием); справа — ghost-кнопки
  `Share`/`More` только если действие реально работает, иначе их нет.
- Лента: `padding: 24px 0 32px`, вертикальный ритм 20px. Автоскролл только когда
  пользователь уже внизу; иначе появляется пилюля «Вниз» по центру над композером.

### Сообщения

- Пользователь: справа, блок `--surface-2`, `--radius` 10px, `padding: 10px 14px`,
  max-width 78%, текст `--text-base`, перенос строк как ввёл.
- Нейра: без пузыря и без аватара-кружка. Метка «Нейра» 12px `--text-subtle` над
  текстом, ниже — обычная типографика `--text-base` с межстрочным 24px на всю ширину
  колонки. Это главное отличие от «чата в мессенджере»: длинный ответ читается как статья.
- Markdown: заголовки 18/16px, списки с отступом 20px, `code` — `--font-mono` 13px на
  `--surface-2` с паддингом 2px 5px, блок кода — `--surface-2`, граница, 13px, скролл по X,
  кнопка `Copy` справа сверху (появляется на hover и на focus). Ссылки — `--accent`,
  `text-underline-offset: 3px`. Таблицы — границы `--border`, ячейки 8px 12px.
- Hover по сообщению показывает справа снизу ghost-кнопку `Copy` 24px (и `Retry` для
  последнего ответа ассистента, если запрос повторяем).
- Поток: курсор-каретка 2px `--accent` мигает 1s steps(2) после последнего символа,
  `aria-live="polite"` на контейнере ответа; «Нейра печатает» — три точки 4px,
  анимируются `opacity` со сдвигом 120ms, `prefers-reduced-motion` → статичные.
- Ошибка: полоса `--danger-quiet`, рамка `--danger` 1px, текст 13px, кнопка «Повторить».

### Композер

- Контейнер: `--surface-2`, рамка `--border`, `--radius-lg`, `padding: 10px 10px 10px 16px`,
  тень `--shadow-panel`, ширина колонки, отступ снизу 16px, sticky.
- `textarea` прозрачная, без рамки, авто-рост 1–6 строк (24px–144px), placeholder
  «Спросите Нейру…» `--text-subtle`, Enter отправляет, Shift+Enter перенос.
- Справа кнопка 32×32 `--radius-full`: активна — фон `--accent`, иконка `ArrowUp`
  `--accent-ink`; неактивна — `--surface-3`, иконка `--text-subtle`.
  Во время потока — `Square` в `--surface-3` (стоп), подпись `aria-label`.
- Под композером одна строка 11px `--text-subtle`: подсказка «Enter — отправить,
  Shift+Enter — новая строка». Больше ничего.
- Фокус: кольцо `0 0 0 1px var(--accent)` на контейнере, без внешнего свечения.

### Пустое состояние

По центру колонки: знак Нейры 40px (SVG, `--accent`), заголовок `--text-2xl`
«Чем помочь?», одна строка `--text-muted` 15px, ниже 3–4 чипа-подсказки
(`--surface-2`, рамка, 13px, `--radius-full`, hover `--surface-3`). Подсказки — только
реальные сценарии продукта: «Что нового в памяти?», «Суммируй вчерашний диалог»,
«Проверь состояние сервера». Никаких выдуманных возможностей.

## 4. Вход и регистрация

- Двухколоночный экран ≥1024px: слева 45% — `--bg` с волосяной сеткой 96px
  (`linear-gradient` 1px, opacity 0.04) и по центру: знак 32px, «Neyra» 22px/600,
  одна строка 15px `--text-muted` о продукте, ниже 3 строки 13px с иконками `Check`
  `--accent` — только то, что правда (свой сервер, память диалогов, роли доступа).
- Справа 55% — `--surface`, по центру карточка шириной 360px, без рамки-«коробки в коробке»:
  заголовок `--text-xl` («Вход» / «Регистрация»), подпись 13px `--text-muted`,
  поля 44px высотой, `--surface-2`, `--radius`, рамка `--border`, фокус — рамка `--accent`.
  Подпись поля 13px, sentence case, над полем (не placeholder вместо подписи).
  Ошибка — 12px `--danger` под полем и `aria-describedby`; общая ошибка сервера — полоса сверху карточки.
  Кнопка — `--accent`, 44px, на всю ширину, текст `--accent-ink` 500.
  Ссылка-переход между входом и регистрацией — 13px `--text-muted` + `--accent` на действии.
- Мобильный (<1024px): одна колонка, карточка на всю ширину с отступами 20px,
  логотип сверху. Ничего не обрезается при 390×844 и при клавиатуре.

## 5. Доступность и состояния

- Видимый `:focus-visible`: кольцо 1px `--accent` + `outline-offset: 2px`, мгновенно.
- Контраст текста ≥ 4.5:1 на своих фонах; `--text-subtle` — только для второстепенных
  подписей, не для тела ответа.
- Все иконочные кнопки имеют `aria-label`; статусы — `role="status"`.
- `prefers-reduced-motion: reduce` убирает каретку, точки и drawer-анимацию.
- Клавиатура: Tab-порядок сайдбар → хедер → лента → композер; Esc закрывает drawer.
- Состояния контролов обязательны: default, hover, active (`scale(0.98)`), focus,
  disabled (`opacity .4`, курсор default), loading (спиннер 14px вместо иконки).

## 6. Качество кода

- Компоненты: `src/components/ui/*` (Button, IconButton, TextField, Chip, Avatar) поверх
  `@neyra/ui`; страницы собираются из них, без копипасты классов.
- Один контейнер ширины для контента: класс `.content-column { max-width: 720px; margin-inline: auto; padding-inline: 24px }` (16px на мобильном).
- Утилитарные классы Tailwind — допустимы, произвольные `[...]` значения с hex — нет.
- Никаких новых зависимостей, кроме `lucide-react`, `react-markdown`, `remark-gfm`
  (проверить, что они уже есть или добавить осознанно в `package.json`).
- Тесты: существующие тесты чата должны проходить; добавить проверку, что пустое
  состояние, отправка и стоп-кнопка остаются доступны по роли/лейблу.

## 7. Приёмка

Скриншоты обязательны (1440×900 и 390×844), по одному на: `/login`, `/signup`,
`/chat` пустой, `/chat` с диалогом (пользователь + длинный ответ с кодом и списком),
`/chat` с ошибкой. Проверяется: нет горизонтального скролла, хедер и композер не
перекрывают контент, сайдбар корректно уезжает на 390px, фокус видим, контраст ок.
