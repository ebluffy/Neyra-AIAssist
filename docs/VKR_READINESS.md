# Готовность прототипа к ВКР

Срез 2026-10-16. Это проверка критериев из PLAN §0, не процент по числу файлов
или задач. «Серверная половина» — согласованная контрольная точка перед клиентом.

| Часть | Реализация | Подтверждение / остаток |
| --- | --- | --- |
| Серверное ядро, конфигурация, Control API, auth и роли | Реализованы | Offline/API/CI; работа на целевом стенде — отдельная приёмка |
| Чат, streaming, brain/talk/vision, режимы | Реализованы | Pipeline с заглушками проверен; соблюдение инструкций настоящими моделями ещё не подтверждено |
| Память и фоновые задачи | Реализованы; #27 смержен, АР LGTM | Изоляция, миграции временных SQLite, ошибки и wipe покрыты тестами; качество retrieval и production-copy migration — live |
| Mood & Relations (§7.5) | Ещё не реализованы; ближайшая очередь | Сохраняемое настроение, отношения по person_id, decay и управление — отдельный следующий этап |
| Dashboard: статус, модули, память, настройки, системные действия | Реализован | Локальный API + Chromium desktop/mobile; исправления #27 смержены |
| Backup/restore и диагностика | Реализованы | Offline-регрессии; рестарт/восстановление целевого хоста — live |
| Один работающий модуль | Discord/music реализованы; локальный example проверен | Настоящие Discord/GIF/music/browsermcp требуют пользовательской проверки |
| Тексты/промпты как ресурсы, ru/en | Первая поставка §12/14 реализована локально | 70 service blocks, loader/validator и два сообщения ru/en; полная локализация ещё открыта |
| Двухботовый голос | §11 отложен после ВКР / при наличии времени | Не блокирует ближайшую серверную очередь |
| Windows/Linux клиент: подключение, чат, статус, модуль | Только scaffold | Полностью после серверного контура; dashboard не заменяет этот критерий ВКР |
| Поставка клиента и демонстрация полного пути | Не реализованы | Отдельные сборки/приёмка Windows и Linux, затем демонстрация сервер → клиент |

Серверные исходники и локальная проверка — существенная готовая часть, однако
заявлять «50% полностью работает» до выбранного измеримого набора сценариев и
live-приёмки было бы неточно. #27 уже смержен. Следующий рубеж: завершить §14,
реализовать §7.5 и пройти пользовательскую проверку серверного сценария.
§10/§3b — в конце, §9/§11 — после ВКР либо при наличии времени. Весь исследовательский backlog
не требуется реализовывать, чтобы показать прототип по неизменной теме ВКР.

Деплой, реальные LLM/Discord и данные стенда не используются автоматически.
