# Manifest Reference (`plugin.yaml`)

Обязательные/ключевые поля:
- `id`
- `name`
- `version`
- `enabled`
- `lifecycle`: `resident` | `on_demand`
- `main_script`
- `cli_modes` (опционально)

`enabled` — единственная точка вкл/выкл плагина.
