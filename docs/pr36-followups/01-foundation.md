## Работа

Воспроизвести жалобы владельца в готовом AppImage и NSIS; X11-smoke уже подтвердил тему и ручное отключение с черновиком, но KDE Wayland и обновление старого профиля открыты. Проверка подключения уже использует health + api_version из стабильного контракта API; offline-тесты покрывают закрытый OpenAPI, отказ сети, авторизацию и несовместимую/отсутствующую версию. Проверить chat streaming, историю и профиль при reconnect; расследовать ввод URL и имени на реальном железе. Подтверждённая гонка: в AppImage быстрый WSS done приходит до завершения IPC chat; ответ появляется выше сообщения пользователя, «Нейра думает» остаётся. В локальном исправлении user добавляется до IPC, terminal event завершает thinking без повторного включения при IPC ack. Hook заранее выделяет request ID, Rust принимает его как необязательный аргумент chat, проверяет UUID и передаёт существующему bridge-протоколу. При отказе IPC оптимистичная строка откатывается, черновик сохраняется. Поздние IPC и bridge-события после Stop/отмены/обрыва не восстанавливают ход.

## Готово, когда

- [ ] Готовый пакет: новый и существующий профиль, закрытый OpenAPI, неверный токен, приватный чат с ответом, Stop, 503/обрыв и восстановление без дублирования, черновик и тема после нужных переходов, модули/статус и keyring без plaintext. Регрессия: синтетический backend посылает done до завершения IPC; сообщение пользователя идёт первым, индикатор гаснет, следующий ход доступен.
- [ ] Результаты воспроизводимы: SHA, ОС, тип пакета, шаги и фактическое поведение. CI, симуляция и проверка реального оборудования указаны отдельно.
- [ ] Уточнить PLAN только по факту проверок; §0 и §9 оставить без изменений.

Локальная реализация гонки покрыта регрессиями настоящего useDesktop через React renderer с отложенным IPC, ранним done, следующим ходом, ошибкой/отменой, stale ID и handled=true. Эти тесты подменяют только IPC/events и не являются приёмкой AppImage/NSIS или реального оборудования. Rust-сборка и аппаратная приёмка остаются открытыми. Merge возможен только в ветку PR #36 после отдельной проверки.
