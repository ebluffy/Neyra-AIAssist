## Работа

Сверить готовый UI и голосовой/файловый контур с §3b. Проверить YAML hot reload, редактирование/удаление, подтверждение голосового черновика, capabilities только в рантайме, нативные диалоги import/export.

## Готово, когда

- [ ] В готовых Windows/Linux пакетах создать через UI, файл и голос; исполнять только по политике, показывать ошибки YAML, отклонять секреты/выход за разрешения, переносить команды на другой ПК без токенов; Discord/dashboard не получают команды.
- [ ] Результаты воспроизводимы: SHA, ОС, тип пакета, шаги и фактическое поведение. CI, симуляция и проверка реального оборудования указаны отдельно.
- [ ] Уточнить PLAN только по факту проверок; §0 и §9 оставить без изменений.

Этот draft фиксирует объём задачи. В PR уже есть изменение кода вне черновика: имена файлов команд длиннее 96 байт (multi-byte) больше не создаются новыми, а уже лежащие на диске такие файлы остаются открываемыми, редактируемыми и удаляемыми; перенос в бэкап при import/replace сначала проверяет все имена, потом двигает файлы. Приёмочные пункты выше по-прежнему открыты. Merge возможен только в ветку PR #36 после отдельной проверки.
