Этот PR содержит документ объёма и правку снимков: в одной сессии действует только последний `screenshot_id`, старые id и координаты отклоняются, чужие сессии не затрагиваются. Проверка на живых Windows/KDE Wayland/X11 с несколькими мониторами и DPI ещё не выполнена — она остаётся за владельцем. Merge возможен только в ветку PR #36 после отдельной проверки.

## Сделано в этом PR

- `remember()` удаляет прежние снимки своей сессии; `find_shot()` сверяет session и TTL, поэтому старый `screenshot_id` после нового capture не принимается.
- Память ограничена 8 записями метаданных, пиксели не хранятся.
- `ShotStore` хранит метаданные снимков; продукт использует общий экземпляр, каждый тест — отдельный локальный экземпляр без сброса GLOBAL.
- Неудачный capture инвалидирует предыдущий id сессии; Stop/disconnect очищают её снимки.
- Регрессии проверяют смену снимка, изоляцию сессий/хранилищ, ошибку capture и очистку при Stop.
- Пакет Rust-изменений SHA256 `774d57142b39a4737a32f21d06613f72e285e49532c2afafefef3de7949b84d6` проверен на изолированной Instabox: 192 Rust-теста, fmt и Clippy прошли. Независимое read-only ревью этого пакета не выявило P1/P2/P3. Это offline-проверки, не аппаратная приёмка.
