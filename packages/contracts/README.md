# Контракты волны 2

Эта server-ветка создана до клиентского монорепо. `src/index.ts` и исходные тесты взяты из локальной `web/p2-chat` и дополнены stored attachments, usage и phase. Корневой npm-монорепо здесь не создаётся. При объединении с PR #74 сохранить эти изменения в общем @neyra/contracts и прогнать штатный Vitest/typecheck сайта.

Usage имеет все четыре целых неотрицательных числа (context_limit > 0). Частичный usage невалиден; ядро не выводит его, если провайдер не сообщил все четыре значения. Нет estimations/fallback из конфига модели. SSE/WS done usage необязателен; model_trace не является публичным контрактом.
Вложения: id — 32 hex символа, kind image/file, разрешённый MIME, name и size до 8 MiB. Только эти metadata передаются в WS; URL/path/base64 от клиента не принимаются. До четырёх ссылок.
