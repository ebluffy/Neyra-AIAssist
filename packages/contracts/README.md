# Контракты волны 2

Эта server-ветка создана до клиентского монорепо. `src/index.ts` и исходные тесты взяты из локальной `web/p2-chat` и дополнены stored attachments, usage и phase. Корневой npm-монорепо здесь не создаётся. При объединении с PR #74 сохранить эти изменения в общем @neyra/contracts и прогнать штатный Vitest/typecheck сайта.

Usage: `{total:{used?,limit?,threshold_pct?},lanes:{talk:{used?,limit?},brain:{used?,limit?},memory:{used?,limit?},vision:{used?,limit?}}}`. used ≥0 — provider input tokens, limit >0 — configured context window. Unknown fields are absent; total fields require all four lane readings. No fabricated zero or default 80. Current core has no percentage compression policy, so threshold_pct is absent. ContextLimitsSchema extends usage with required policy:{compaction_enabled:boolean,mode:"messages"|"off",threshold_messages:int} in REST data for GET /v1/context/limits; WS usage does not contain policy. mode is messages only when enabled && on_stm_threshold && threshold_messages>0. WS server always emits usage, SSE schema keeps usage optional for compatibility with older cores. model_trace is never public.
Вложения: id — 32 hex символа, kind image/file, разрешённый MIME, name и size до 8 MiB. Только эти metadata передаются в WS; URL/path/base64 от клиента не принимаются. До четырёх ссылок.
