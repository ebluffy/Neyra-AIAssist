# mobile (задел)

Будущий мобильный клиент Neyra. Здесь пока только место и правила.

- Общее с сайтом и приложением: `packages/contracts` (DTO, zod-схемы, HTTP/WSS-клиент) и токены дизайна из `packages/ui`.
- Компоненты `packages/ui` — DOM-only (Radix), поэтому мобильный клиент их не импортирует, а повторяет по токенам.
- Решение о стеке (Expo/React Native или PWA) не принято; до него папка не должна обрастать кодом.
